# About the Project
A Java app that helps you stay focused and cuts distractions while you work. I started Focus-Cat for a client struggling to stay productive while balancing school, work, and extracurriculars. I interviewed the client about what they needed, designed the interface, and coded the whole thing by hand in Java.

# Features
* Pomodoro and countdown timer for working in focused intervals
* To-do list that allows tasks to be sorted by date created
* Progress Tracker that graphs hours of focused work over time
* Gamified reward system: productive hours translates to coins that can be used to purchase items to decorate the app
* Persistent storage: data is saved locally using Gson

# Built with
* Java 21
* Maven
* Gson
* JFreeChart

# Getting Started
**Prerequisites**
* JDK 21 or newer
* [Maven](https://maven.apache.org/download.cgi)

**Build and run**
```bash
git clone https://github.com/winnie-c8/Focus-Cat.git
cd Focus-Cat
mvn clean package
java -jar target/focusapp-0.0.1-SNAPSHOT.jar
```
Alternatively, open the project in an IDE such as Eclipse and run Main.
